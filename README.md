# Test Game

## 프로젝트 개요

- 프로젝트 이름: Test Game
- 장르: 자동사냥 방치형 웹게임
- 전체 개발 단계: 총 10단계
- 현재 단계: 1단계
- 현재 단계 이름: 프로젝트 기반 및 개발단계 관리
- 현재 상태: 진행 중

## 프로젝트 목적

플레이어가 필드에서 몬스터를 선택하고 자동으로 접근한 뒤 전투를 진행하며, 이후 보상·성장·아이템·저장·방치 진행으로 확장되는 자동사냥 방치형 웹게임을 단계적으로 개발한다. 각 단계의 목표와 완료 조건을 문서로 관리하여 사용자와 개발 AI가 현재 개발 위치를 정확히 파악할 수 있도록 한다.

개발 로드맵은 총 10단계로 구성되며, 현재는 1단계인 **프로젝트 기반 및 개발단계 관리**를 진행한다. 현재 단계가 완료되어도 사용자가 다음 단계 진행을 명시하기 전까지는 1단계를 유지한다.

## 문서

- [개발 로드맵](docs/ROADMAP.md)
- [현재 개발 상태](docs/STATUS.md)

아직 플레이어, 몬스터, 이동, 전투를 포함한 실제 게임 기능은 구현되지 않았다. 이번 단계에서는 프로젝트 기반과 개발 단계 관리 문서만 준비한다.
