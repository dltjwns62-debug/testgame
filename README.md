# Test Game

## 프로젝트 개요

- 프로젝트 이름: Test Game
- 장르: 자동사냥 방치형 웹게임
- 전체 개발 단계: 총 10단계
- 현재 단계: 1단계
- 현재 단계 이름: 프로젝트 기반 및 개발단계 관리
- 현재 상태: 1단계 완료
- 현재 안정 버전: `main`
- 검수 완료 태그: `review-stage-01-v1`

## 프로젝트 목적

플레이어가 필드에서 몬스터를 선택하고 자동으로 접근한 뒤 전투를 진행하며, 이후 보상·성장·아이템·저장·방치 진행으로 확장되는 자동사냥 방치형 웹게임을 단계적으로 개발한다. 각 단계의 목표와 완료 조건을 문서로 관리하여 사용자와 개발 AI가 현재 개발 위치를 정확히 파악할 수 있도록 한다.

개발 로드맵은 총 10단계로 구성되며, 현재 1단계인 **프로젝트 기반 및 개발단계 관리**의 검수와 `main` 반영이 완료됐다. 다음 예정 단계는 2단계인 **필드 화면에 플레이어와 몬스터 표시**이며, 별도의 2단계 시작 명령 전까지 시작하지 않는다.

최초 저장소 생성 과정에서 검수 전에 `main`에 초기 문서 커밋이 반영된 사실은 일회성 부트스트랩 예외로 기록하고 기존 Git 기록을 보존했다. 이후 검수 승인된 `review-stage-01-v1` 작업을 `main`에 반영했으며, 해당 승인으로 1단계를 완료 확정했다.
