# Test Game

## 프로젝트 개요

- 프로젝트 이름: Test Game
- 장르: 자동사냥 방치형 웹게임
- 전체 개발 단계: 총 10단계
- 현재 단계: 1단계
- 현재 단계 이름: 프로젝트 기반 및 개발단계 관리
- 현재 상태: 검수 대기
- 현재 작업 브랜치: `stage-01-project-setup`
- 검수 기준 태그: `review-stage-01-v1`

## 프로젝트 목적

플레이어가 필드에서 몬스터를 선택하고 자동으로 접근한 뒤 전투를 진행하며, 이후 보상·성장·아이템·저장·방치 진행으로 확장되는 자동사냥 방치형 웹게임을 단계적으로 개발한다. 각 단계의 목표와 완료 조건을 문서로 관리하여 사용자와 개발 AI가 현재 개발 위치를 정확히 파악할 수 있도록 한다.

개발 로드맵은 총 10단계로 구성되며, 현재는 1단계인 **프로젝트 기반 및 개발단계 관리**를 검수 대기 중이다. 검수 통과와 사용자의 별도 승인 전에는 1단계를 완료 상태로 변경하거나 다음 단계로 진행하지 않는다.

최초 저장소 생성 과정에서 검수 전에 `main`에 초기 문서 커밋이 반영된 사실이 있으나, 이는 정식 검수 승인이나 단계 완료를 의미하지 않는 일회성 부트스트랩 예외다. 기존 Git 기록은 보존하며, 현재 검수 대상은 `stage-01-project-setup`의 `review-stage-01-v1` 태그다.
