# Test Game 개발 로드맵

## 로드맵 기준

- 전체 단계: 10단계
- 현재 단계: 2단계
- 현재 단계 이름: 필드 화면에 플레이어와 몬스터 표시
- 현재 단계 상태: 검수 대기 (`review_pending`)
- 현재 작업 브랜치: `stage-02-field-rendering`
- 1단계 승인 태그: `review-stage-01-v1`
- 2단계 최초 검수 태그: `review-stage-02-v1` — 수정 요청
- 2단계 현재 검수 태그: `review-stage-02-v2`
- 다음 단계: 3단계 — 몬스터 우클릭 선택 및 자동 접근
- 완료된 단계: 1단계
- 검수 승인된 단계: 1단계
- `main` 반영 여부: 미반영

각 단계의 상태는 다음 값으로 관리한다.

- `not_started`: 시작 전
- `in_progress`: 작업 중
- `review_pending`: 구현 후 검수 대기
- `changes_requested`: 검수 후 수정 필요
- `approved`: 검수 통과, 병합 대기
- `completed`: `main` 반영까지 완료

각 단계는 목표와 완료 조건을 검수한 뒤 진행한다. 현재 단계 번호는 2이며, 현재 2단계는 `review_pending` 상태다. 1단계는 `completed` 상태로 유지하고, 3단계는 `not_started` 상태로 유지한다. `review-stage-02-v1` 검수는 수정 요청으로 종료됐으며 현재 재검수 기준은 `review-stage-02-v2`다.

검수 대상 버전은 tracked 파일 안의 현재 커밋 해시가 아니라 변경되지 않는 Git 태그로 관리한다. 검수 태그는 `review-stage-XX-vN` 형식을 사용하고, 기존 원격 태그는 이동하거나 덮어쓰지 않는다. 1단계 승인 태그는 `review-stage-01-v1`이며, 2단계 최초 검수 태그 `review-stage-02-v1`은 수정 요청 기록으로 보존하고 현재 재검수 태그는 `review-stage-02-v2`다.

최초 저장소 생성 과정에서 검수 전에 `main`에 초기 문서 커밋이 반영된 사실은 일회성 부트스트랩 예외로 기록했다. 해당 당시 반영은 정식 검수 승인을 의미하지 않았으며, 이후 승인된 `review-stage-01-v1`을 `main`에 반영해 1단계를 완료 확정했다.

- 문서 간 단계 번호와 이름 일치 여부 검증

### 완료 조건 — 모두 충족

### 해당 단계에서 구현하지 않을 항목

## 3단계: 몬스터 우클릭 선택 및 자동 접근

### 단계 상태

`not_started` — 2단계 승인 후 별도 시작 명령 대기

### 목표

플레이어가 몬스터를 우클릭으로 선택하면 플레이어가 해당 몬스터를 향해 자동으로 접근하도록 한다.

### 주요 구현 항목

- 몬스터 우클릭 이벤트 처리
- 선택된 몬스터의 시각적 상태 표시
- 플레이어의 자동 접근 및 정지 조건
- 선택 대상 초기화 처리

### 완료 조건

- 몬스터 우클릭으로 대상이 선택된다.
- 선택 대상이 명확히 구분된다.
- 플레이어가 선택 대상에 자동으로 접근한다.
- 접근 완료와 대상 해제 동작이 검증된다.

### 해당 단계에서 구현하지 않을 항목

- 접촉 시 전투 화면 전환
- 공격력·방어력 계산
- 승리·패배 및 보상
- 경험치와 아이템

## 4단계: 플레이어와 몬스터 접촉 시 전투 화면 전환

### 목표

플레이어가 선택한 몬스터에 접촉하면 필드에서 전투 화면으로 전환되도록 한다.

### 주요 구현 항목

- 접촉 판정
- 전투 화면 전환
- 전투 대상 전달
- 필드 복귀를 고려한 화면 상태 관리

### 완료 조건

- 플레이어와 몬스터의 접촉이 판정된다.
- 접촉한 대상과 함께 전투 화면으로 전환된다.
- 잘못된 대상이나 중복 전환이 방지된다.
- 전환 동작이 검증된다.

### 해당 단계에서 구현하지 않을 항목

- 실제 자동 공격
- 피해량 계산
- 승리·패배 처리
- 보상 및 몬스터 재생성

## 5단계: 기본 자동전투

### 목표

전투 화면에서 플레이어와 몬스터가 정해진 규칙에 따라 자동으로 공격하도록 한다.

### 주요 구현 항목

- 공격 주기
- 기본 피해량 계산
- 플레이어와 몬스터의 체력 변화 표시

### 완료 조건

- 전투가 자동으로 진행된다.
- 공격 주기와 피해량이 일관되게 동작한다.
- 양쪽 체력 변화가 화면에 반영된다.
- 전투 중복 실행과 비정상 상태가 검증된다.

### 해당 단계에서 구현하지 않을 항목

## 6단계: 승리·패배, 보상, 몬스터 재생성

### 목표

### 주요 구현 항목

- 승리·패배 판정
- 전투 결과 화면 또는 메시지
- 기본 보상 지급
- 몬스터 제거 및 재생성
- 필드 복귀 처리

### 완료 조건

- 승리와 패배가 정확히 구분된다.
- 승리 시 보상이 지급된다.
- 패배 시 정의된 결과가 적용된다.
- 처치된 몬스터가 규칙에 따라 재생성된다.
- 결과 처리가 중복되지 않는다.

### 해당 단계에서 구현하지 않을 항목

- 복잡한 성장 트리
- 장비·인벤토리 시스템
- 장기 방치 진행
- 온라인 동기화

- 레벨 상승에 따라 능력치가 갱신된다.
- 성장 상태가 새로고침 및 관련 흐름에서 일관된다.
