# Test Game

## 프로젝트 개요

- 프로젝트 이름: Test Game
- 장르: 자동사냥 방치형 웹게임
- 전체 개발 단계: 총 10단계
- 현재 단계: 2단계
- 현재 단계 이름: 필드 화면에 플레이어와 몬스터 표시
- 현재 상태: 검수 대기
- 현재 안정 버전: `main`
- 검수 완료 태그: `review-stage-01-v1`
- 현재 작업 브랜치: `stage-02-field-rendering`
- 2단계 검수 태그: `review-stage-02-v1`

## 프로젝트 목적

플레이어가 필드에서 몬스터를 선택하고 자동으로 접근한 뒤 전투를 진행하며, 이후 보상·성장·아이템·저장·방치 진행으로 확장되는 자동사냥 방치형 웹게임을 단계적으로 개발한다. 각 단계의 목표와 완료 조건을 문서로 관리하여 사용자와 개발 AI가 현재 개발 위치를 정확히 파악할 수 있도록 한다.

개발 로드맵은 총 10단계로 구성되며, 1단계 **프로젝트 기반 및 개발단계 관리**는 완료됐다. 현재 2단계인 **필드 화면에 플레이어와 몬스터 표시**를 구현하고 검수 대기 중이다. 다음 예정 단계는 3단계이며, 2단계 승인 전에는 `main`에 반영하지 않는다.

최초 저장소 생성 과정에서 검수 전에 `main`에 초기 문서 커밋이 반영된 사실은 일회성 부트스트랩 예외로 기록하고 기존 Git 기록을 보존했다. 이후 검수 승인된 `review-stage-01-v1` 작업을 `main`에 반영해 1단계를 완료 확정했다.

## 현재 구현

- Phaser 기반 960×540 필드 화면
- 고정된 플레이어 1명과 몬스터 4마리
- 플레이어·몬스터 이름표와 2단계 안내 문구
- 브라우저 크기에 맞춰 비율을 유지하는 화면 표시

아직 몬스터 선택, 이동, 전투, 체력, 경험치, 아이템, 자동사냥, 저장 기능은 구현하지 않았다.

## 기술 및 실행

사용 기술은 Phaser, TypeScript, Vite이며 패키지는 npm으로 관리한다. Node.js가 필요하다.

```bash
npm install
npm run dev
```

빌드와 타입 검사는 다음 명령으로 실행한다.

```bash
npm run build
npm run typecheck
```

2단계는 아직 사용자 실행 테스트와 ChatGPT 코드 검수를 통과하지 않았으므로 최종 승인되지 않았다. 사용자는 [실행 및 수동 테스트](docs/TESTING.md)의 항목을 확인한다.

아직 플레이어, 몬스터, 이동, 전투를 포함한 실제 게임 기능은 구현되지 않았다. 이번 단계에서는 프로젝트 기반과 개발 단계 관리 문서만 준비한다.
