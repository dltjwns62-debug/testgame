# 2단계 실행 및 수동 테스트

## 설치

```bash
node --version
npm --version
npm install
```

Node.js는 `20.19.0 이상 또는 22.12.0 이상`이어야 한다. 요구 버전보다 낮으면 Node.js를 갱신한다.

```bash
npm run dev
```

## 접속

터미널에 표시되는 로컬 주소를 브라우저에서 연다.

기본 주소 예시:

```text
http://localhost:5173
```

포트가 사용 중이면 Vite가 다른 포트를 사용할 수 있으므로 터미널에 실제 표시된 주소를 사용한다.

## 2단계 수동 테스트 목록

```text
[ ] 브라우저에서 게임 화면이 열린다.
[ ] 960:540 비율의 필드 화면이 보인다.
[ ] 플레이어 1명이 보인다.
[ ] 플레이어 이름표가 보인다.
[ ] 몬스터가 4마리 이상 보인다.
[ ] 몬스터 이름표가 각각 보인다.
[ ] 플레이어와 몬스터가 서로 겹치지 않는다.
[ ] 브라우저 크기를 바꿔도 게임 비율이 유지된다.
[ ] 불필요한 페이지 스크롤바가 생기지 않는다.
[ ] 아무 조작을 하지 않아도 오브젝트가 움직이지 않는다.
[ ] 브라우저 개발자 도구 콘솔에 오류가 없다.
[ ] 클릭하거나 우클릭해도 아직 게임 기능이 작동하지 않는다.
```

사용자 실행 테스트 상태: 미실시

## 작은 브라우저 창 확인 크기

다음 크기에서 게임 화면 전체가 보이고 16:9 비율이 유지되는지 확인한다.

- `1200 × 800`
- `800 × 600`
- `800 × 400`
- `400 × 800`

자동 확인 결과:

- `npm ci`: 통과
- `npm run typecheck`: 통과
- `npm run build`: 통과
- 개발 서버 시작 및 브라우저 렌더링: 통과
- 반응형 viewport (`1200×800`, `800×600`, `800×400`, `400×800`): 통과
- 네 viewport 모두 16:9, 화면 내 맞춤, 스크롤 없음, 콘솔 오류·경고 없음
