# Test Game

## 프로젝트 개요

- 프로젝트 이름: Test Game
- 장르: 자동사냥 방치형 웹게임
- 전체 개발 단계: 총 10단계
- 현재 단계: 5단계
- 현재 단계 이름: 기본 자동전투
- 현재 상태: 완료 (`completed`)
- 현재 안정 버전: `main`
- 1단계 승인 태그: `review-stage-01-v1`
- 현재 작업 브랜치: `main`
- 2단계 최초 검수 태그: `review-stage-02-v1` — 수정 요청
- 2단계 승인 태그: `review-stage-02-v2`
- 3단계 현재 검수 태그: `review-stage-03-v1`
- 3단계 완료 태그: `stage-03-completed`
- 4단계 현재 검수 태그: `review-stage-04-v1`
- 4단계 완료 태그: `stage-04-completed`
- 5단계 현재 검수 태그: `review-stage-05-v1`
- 5단계 완료 태그: `stage-05-completed`

## 프로젝트 목적

플레이어가 필드에서 몬스터를 선택하고 자동으로 접근한 뒤 전투를 진행하며, 이후 보상·성장·아이템·저장·방치 진행으로 확장되는 자동사냥 방치형 웹게임을 단계적으로 개발한다. 각 단계의 목표와 완료 조건을 문서로 관리하여 사용자와 개발 AI가 현재 개발 위치를 정확히 파악할 수 있도록 한다.

개발 로드맵은 총 10단계로 구성되며, 1단계부터 5단계 **기본 자동전투**까지 완료됐다. 현재 안정 버전은 `main`이며, 다음 예정 단계는 6단계다. 6단계는 별도 시작 명령 전까지 시작하지 않는다.

최초 저장소 생성 과정에서 검수 전에 `main`에 초기 문서 커밋이 반영된 사실은 일회성 부트스트랩 예외로 기록하고 기존 Git 기록을 보존했다. 이후 검수 승인된 `review-stage-01-v1` 작업을 `main`에 반영해 1단계를 완료 확정했다.

## 현재 구현

- Phaser 기반 960×540 필드 화면
- 고정된 플레이어 1명과 몬스터 4마리
- 플레이어·몬스터 이름표와 2단계 안내 문구
- 브라우저 크기에 맞춰 비율을 유지하는 화면 표시
- 몬스터 우클릭 선택과 단일 선택 표시
- 선택 몬스터를 향한 플레이어 자동 접근
- 이동 중 목표 변경과 접촉 거리 정지
- 접촉 시 BattleScene 전환
- 선택한 몬스터와 정적 HP 정보 전달
- Return to Field를 통한 필드 상태 보존 복귀
- 플레이어와 몬스터의 기본 자동 공격
- 공격 주기 및 고정 피해량 적용
- 실시간 HP 텍스트·HP 바·최근 공격 로그
- HP 0에서 중립적 전투 정지

아직 승패, 보상, 경험치, 아이템, 자동사냥, 저장 기능은 구현하지 않았다.

## 기술 및 실행

사용 기술은 Phaser, TypeScript, Vite이며 패키지는 npm으로 관리한다. Node.js `20.19.0 이상 또는 22.12.0 이상`이 필요하다. 버전이 낮다면 Node.js를 갱신해야 한다.

Node.js 버전은 다음 명령으로 확인한다.

```bash
node --version
npm install
npm run dev
```

빌드와 타입 검사는 다음 명령으로 실행한다.

```bash
npm run build
npm run typecheck
```

1단계부터 5단계까지 코드 검수와 사용자 실행 테스트가 완료되어 `main`에 반영됐다. 승패·보상·몬스터 재생성 등 6단계 이후 기능은 아직 구현하지 않았다.

현재 알려진 문제: 필드 상단 단계 안내가 `Stage 4`로 남아 있으며, 자동전투에는 영향이 없다. 6단계 작업 브랜치에서 수정 예정이다.
