# 2단계 실행 및 수동 테스트

## 설치

```bash
node --version
npm --version
npm install
```

Node.js는 `20.19.0 이상 또는 22.12.0 이상`이어야 한다. 요구 버전보다 낮으면 Node.js를 갱신한다.

```bash
npm run dev
```

```text
http://localhost:5173
```

- 현재 검수 태그: `review-stage-06-v2`
