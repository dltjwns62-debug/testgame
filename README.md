# Test Game

## 프로젝트 개요

- 프로젝트 이름: Test Game
- 장르: 자동사냥 방치형 웹게임
- 전체 개발 단계: 10단계
- 현재 단계: 6단계
- 현재 단계 이름: 승리·패배, 보상, 몬스터 재생성
- 현재 상태: 완료 (`completed`)
- 현재 안정 브랜치: `main`
- 6단계 승인 태그: `review-stage-06-v2`
- 완료된 단계: 1단계, 2단계, 3단계, 4단계, 5단계, 6단계
- 다음 예정 단계: 7단계 — 경험치, 레벨, 능력치 성장

프로젝트는 필드에서 몬스터를 선택하고 접근한 뒤 전투를 진행하는 자동사냥 방치형 웹게임을 단계적으로 개발한다. 로드맵은 총 10단계이며, 1단계부터 6단계까지 `main`에 반영되어 완료됐다.

## 6단계 완료 내용

- 승리·패배 판정 및 결과 화면
- 결과 중복 적용 방지
- 몬스터 정의의 공식 Gold와 전달 Gold가 일치할 때만 보상 지급
- Slime별 승리 Gold 보상
- 필드 누적 Gold 표시
- 승리 몬스터 일시 제거 및 3초 후 같은 위치 재생성
- 패배 시 보상 없음 및 몬스터 유지
- 사용자 실행 테스트 통과
- ChatGPT 코드 검수 통과

경험치·레벨·능력치 성장, 아이템·인벤토리, 저장·방치 진행, 온라인 기능은 아직 구현하지 않았다. 7단계는 별도 시작 명령 전까지 시작하지 않는다.

## 알려진 문제

- `favicon.ico`가 없어 브라우저 콘솔에 비차단 404가 표시될 수 있다.
- 게임 실행, 전투, 보상, 몬스터 재생성에는 영향이 없다.
- 수정이 필요하면 다음 작업 브랜치에서 별도 검수한다.

## 기술 및 실행

현재 사용 중인 기술은 Phaser, TypeScript, Vite이며 패키지는 npm으로 관리한다. Node.js `20.19.0 이상 또는 22.12.0 이상`이 필요하다.

```bash
node --version
npm --version
npm ci
npm run dev
```

검증 명령:

```bash
npm run typecheck
npm run build
```
