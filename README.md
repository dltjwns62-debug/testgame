# Test Game

## 프로젝트 개요

- 프로젝트 이름: Test Game
- 장르: 자동사냥 방치형 웹게임
- 전체 개발 단계: 10단계
- 현재 단계: 6단계
- 현재 단계 이름: 승리·패배, 보상, 몬스터 재생성
- 현재 상태: 검수 대기 (`review_pending`)
- 현재 작업 브랜치: `stage-06-results-rewards-respawn`
- 검수 기준 태그: `review-stage-06-v2`
- 완료된 단계: 1단계, 2단계, 3단계, 4단계, 5단계
- 검수 승인된 단계: 1단계, 2단계, 3단계, 4단계, 5단계
- 다음 단계: 7단계 — 경험치, 레벨, 능력치 성장

프로젝트는 필드에서 몬스터를 선택하고 접근한 뒤 전투를 진행하는 자동사냥 방치형 웹게임을 단계적으로 개발한다. 로드맵은 총 10단계이며, 각 단계는 별도 작업 브랜치에서 구현하고 검수 후 `main`에 반영한다.

현재 6단계에서는 승리·패배 결과 화면, Gold 보상, 처치 몬스터 숨김과 3초 후 재생성을 구현했다. 검수 수정에서 몬스터 정의의 공식 Gold와 전달된 보상이 일치할 때만 지급하도록 보강했다. 6단계는 아직 검수 대기 상태이며 `main`에 반영되지 않았다.

## 현재 구현 범위

- Phaser 기반 960×540 필드 화면
- 플레이어와 Slime 1~4 표시
- 몬스터 우클릭 선택 및 자동 접근
- 접촉 시 `BattleScene` 전환
- 기본 자동전투, HP 변화, HP 바, 공격 로그
- 승리·패배 결과 화면과 중복 결과 방지
- 승리 시 Slime별 Gold 보상, 패배 시 무보상
- 승리한 몬스터의 동일 위치·색상·이름 재생성
- 필드 상단 단계 안내: `Stage 6: Results, Rewards and Respawn`

경험치·레벨·능력치 성장, 아이템·인벤토리, 저장·방치 진행, 온라인 기능은 아직 구현하지 않았다. 다음 예정 단계는 7단계이며 별도 시작 명령 전까지 시작하지 않는다.

## 기술 및 실행

현재 사용 중인 기술은 Phaser, TypeScript, Vite이며 패키지는 npm으로 관리한다. Node.js `20.19.0 이상 또는 22.12.0 이상`이 필요하다.

```bash
node --version
npm --version
npm ci
npm run dev
```

검증 명령:

```bash
npm run typecheck
npm run build
```

사용자 실행 테스트는 아직 실시하지 않았으며, ChatGPT 코드 검수도 아직 완료되지 않았다.
